# 来源与第三方说明

本文集中记录工程基础、资料来源和第三方组件，便于维护与归属核对。产品页面和使用文档统一采用“听见”名称，不改变已有代码和资料的来源事实。

| 组成 | 来源与使用范围 |
| --- | --- |
| Java 后端、UniApp 前端 | 基于尚硅谷“谷粒随享”听书课程工程，保留 Maven 模块及前端组件；当前增加本地身份、RBAC、公开内容入口、售后事务、模拟交易与 H5 联调 |
| Python 助手 | 从电商小二工程的 atguigu/listening 适配入口整理，未包含数字人与完整客服工作流 |
| Python 知识服务 | 从掌柜智库工程的 app/listening 适配入口整理，当前采用 SQLite/NumPy、BM25/RRF 与证据核验；未运行原 Milvus/Neo4j 完整应用 |
| Python 运营服务 | 从掌柜问数工程的 listening 适配入口整理，使用指标目录、SQL AST、聚合视图与只读审计；未运行原 ES/Qdrant 完整应用 |
| 初始化数据库、本地 MP3、部分知识资料 | 来自听书课程资料；订单与账号安全资料等为当前工程新增内容。初始化数据规模不是实际运营或用户规模 |
