# 听见 · 项目结构

各服务、资源和脚本均在当前项目内，开发与启动不依赖其他工程目录。

```text
AI_tingshu/
├── backend/java/tingshu-parent/  Java多模块源码及Java测试
├── frontend/uniapp/             UniApp/Vue H5工程
├── python/
│   ├── assistant/              助手、业务代理和管理入口
│   ├── knowledge/              知识检索与原文证据
│   ├── operations/             只读问数和查询审计
│   └── shared/                 模型配置、认证、追踪和统一项目路径
├── scripts/
│   ├── dev/                    启动、停止、环境检查、统一验收
│   ├── setup/                  数据表和视图初始化
│   ├── verify/                 真实服务验收与固定评测
│   └── _bootstrap.py           命令行脚本的统一导入路径
├── requirements/               Python依赖和锁定版本
├── data/                       知识资料和本地示例音频
├── sql/                        初始SQL与版本化增量迁移
├── tests/                      Python自动化测试
├── web/                        助手工作台和管理页面
├── docs/                       架构、接口、部署、求职与演示
├── Start.ps1 / Stop.ps1         两个便捷启动入口
├── docker-compose.yml          隔离数据库服务
├── pyproject.toml              Pytest导入路径和缓存位置
├── README.md                   项目使用入口
├── .env.example / .gitignore   配置示例和版本控制规则
├── .venv/                      本机Python环境，不提交
└── .runtime/                   密钥、运行数据、日志和缓存，不提交
```

## 开发约定

Java 使用 Maven 多模块；默认启动用户、内容、订单服务及必要依赖。H5 构建输出 frontend/uniapp/dist/h5，由助手服务的 /listen/ 提供。Python 公共代码统一位于 python/shared，project_paths.py 定位项目根目录。

主目录 Start.ps1/Stop.ps1 是便捷入口，实际实现位于 scripts/dev。验收脚本经 scripts/_bootstrap.py 设置导入路径，不依赖调用时的工作目录。pyproject.toml 配置 Pytest 导入路径和缓存，不承担应用打包。

## 常用命令

```powershell
.\Start.ps1 -UseLlm -WithKnowledge -WithOperations
.\Stop.ps1
.\scripts\dev\Doctor.ps1
.\scripts\dev\VerifyAll.ps1
.\.venv\Scripts\python.exe scripts\verify\VerifyModelCompatibility.py
```

Python 依赖放在 requirements，前端依赖由 package-lock.json 锁定。构建产物留在对应模块，测试缓存写入 .runtime/cache。复制项目时排除 .venv 和 .runtime，在新机器重新安装依赖并配置密钥。

sql 内已执行迁移不得修改，新增数据库结构或数据修正使用新版本。验收脚本的适用前提见 [部署与验收](部署与验收.md)，工程基础与组件归属见 [来源与第三方说明](来源与第三方说明.md)。
